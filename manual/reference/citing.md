# How to cite

% src: CITATION.cff

How to cite openmobisim: the software's Zenodo DOI and, when published, the paper. Filled at the release.

:::{note}
The software's DOI and a BibTeX entry are written here when the first release is published.
:::

## The starter cases

If you use the [starter cases](cases.md), cite their data too, the version you used:

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23472146.svg)](https://doi.org/10.5281/zenodo.23472146)

Madadi, B. (2026). *openmobisim starter cases: multimodal networks and synthetic demand for four European cities and two benchmark networks* (v1). Zenodo. <https://doi.org/10.5281/zenodo.23472146>

```bibtex
@dataset{madadi2026starter,
  author    = {Madadi, Bahman},
  title     = {openmobisim starter cases: multimodal networks and synthetic demand for four European cities and two benchmark networks},
  version   = {v1},
  publisher = {Zenodo},
  year      = {2026},
  doi       = {10.5281/zenodo.23472146},
}
```
