# How to cite

% src: CITATION.cff

If you use openmobisim in work you publish, cite the version you used, and keep the run fingerprint of every result you
report. When you use the [starter cases](cases.md), cite their data too.

## The software

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23497688.svg)](https://doi.org/10.5281/zenodo.23497688)

Madadi, B. (2026). *openmobisim: An open, reproducible multimodal mobility simulator* (Version 0.1.0) [Computer software]. Zenodo. <https://doi.org/10.5281/zenodo.23497688>

```bibtex
@software{madadi2026openmobisim,
  author    = {Madadi, Bahman},
  title     = {openmobisim: An open, reproducible multimodal mobility simulator},
  version   = {0.1.0},
  publisher = {Zenodo},
  year      = {2026},
  doi       = {10.5281/zenodo.23497688},
}
```

## The starter cases

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23472146.svg)](https://doi.org/10.5281/zenodo.23472146)

Madadi, B. (2026). *openmobisim starter cases: Multimodal networks and synthetic demand for four European cities and two benchmark networks* (Version 1) [Data set]. Zenodo. <https://doi.org/10.5281/zenodo.23472146>

```bibtex
@dataset{madadi2026starter,
  author    = {Madadi, Bahman},
  title     = {openmobisim starter cases: Multimodal networks and synthetic demand for four European cities and two benchmark networks},
  version   = {1},
  publisher = {Zenodo},
  year      = {2026},
  doi       = {10.5281/zenodo.23472146},
}
```

## Other formats

GitHub's "Cite this repository", in the About box of the [repository](https://github.com/bahmanmdd/openmobisim), gives
the software's reference in APA and BibTeX from its
[`CITATION.cff`](https://github.com/bahmanmdd/openmobisim/blob/main/CITATION.cff), which lists both records; each record's Zenodo page
(follow its DOI) exports it in other styles.
