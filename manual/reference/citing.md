# How to cite

% src: CITATION.cff

Cite the version of openmobisim you used. The repository's `CITATION.cff` gives the reference (GitHub's "Cite this
repository" reads it), with the DOI of all versions:

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23497687.svg)](https://doi.org/10.5281/zenodo.23497687)

Madadi, B. (2026). *openmobisim: an open, reproducible multimodal mobility simulator*. Zenodo.
<https://doi.org/10.5281/zenodo.23497687>

With every result you report, name the version and keep the fingerprints of the run's inputs: each run's record,
`run_record.toml`, holds them ([Reproducibility](../concepts/reproducibility.md)).

## The cases

If you use the [cases](cases.md), cite their data too, the version you used:

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24585967.svg)](https://doi.org/10.5281/zenodo.24585967)

Madadi, B. (2026). *openmobisim example cases: multimodal networks and synthetic morning demand for four European
cities and a synthetic test city* (v2). Zenodo. <https://doi.org/10.5281/zenodo.24585967>

```bibtex
@dataset{madadi2026cases,
  author    = {Madadi, Bahman},
  title     = {openmobisim example cases: multimodal networks and synthetic morning demand for four European cities and a synthetic test city},
  version   = {v2},
  publisher = {Zenodo},
  year      = {2026},
  doi       = {10.5281/zenodo.24585967},
}
```

The cases' data keep their own licences, listed with [the cases](cases.md).
